# 🐾 PawCare

## Better Care Starts With Finding the Right Place

PawCare is an animal-care discovery platform designed to help pet owners find relevant and trusted animal-care services in Bengaluru.

The platform helps users discover veterinary clinics, pet hospitals, boarding facilities, diagnostic services, emergency services, and animal welfare organizations.

---

## ✨ Features

### 🔍 Find Animal Care Services
Users can browse and discover different types of animal-care providers, including:

- 🩺 Veterinary Clinics
- 🏥 Pet Hospitals
- 🐾 Pet Boarding Facilities
- 🔬 Pet Diagnostic Services
- 🚑 Emergency Animal Care
- ❤️ Animal Welfare Organizations / NGOs

### 🎯 Search and Filters
The platform provides search and filtering options to help users find suitable animal-care services based on their needs.

Users can filter services by:

- Category
- Rating
- Distance
- Availability / Open Now

### 📍 Location-Based Discovery
PawCare displays animal-care providers based on the selected location and shows relevant information such as:

- Provider name
- Category
- Rating
- Reviews
- Distance
- Availability
- Services offered

### 🤖 AI Care Assistant
PawCare includes an AI Care Assistant that helps users describe their situation and identify the type of animal-care service they may need.

This makes it easier for users who are unsure whether they need a veterinary clinic, emergency care, diagnostics, boarding, or another service.

### 🚨 Emergency Care
The platform highlights emergency animal-care services and provides a clear option for users who need urgent assistance.

### 📱 Modern Responsive Interface
PawCare provides a clean and modern user interface designed for easy navigation and accessibility.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Muskan21-creater/pawcare.git
```

### 2. Navigate to the project folder

```bash
cd pawcare
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will then be available locally through the URL displayed in your terminal.

## 🎯 Project Goal

PawCare aims to simplify the process of finding appropriate animal-care services by bringing relevant providers and care information into one easy-to-use platform.

The project focuses on improving the experience of pet owners by providing:

- Easy service discovery
- Clear provider information
- Search and filtering
- AI-assisted guidance
- Emergency care visibility
